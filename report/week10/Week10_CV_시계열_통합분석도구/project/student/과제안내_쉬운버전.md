# 과제 안내 (아주 쉬운 버전) - 10주차 토요일 프로젝트

> 코딩을 몰라도 괜찮습니다. 앱은 **이미 완성되어 있습니다.**
> 오늘 할 일은 ① 설치하고 ② 3개 탭을 하나씩 써보며 ③ "왜 이렇게 나오지?"를 이번 주 배운 내용으로 설명하고 ④ 화면을 캡처해 내는 것입니다.

## 이 앱이 하는 일 (3가지)

| 탭 | 하는 일 | 이번 주 어디서 배웠나 |
|---|---|---|
| 🖼 이미지 분류 | 사진을 넣으면 "이건 고양이 같아요(확신도 %)"라고 답함 | D1 - ViT |
| 🎨 이미지 생성 | 영어 문장을 넣으면 그림을 새로 그려줌 | D2 - Diffusion |
| 📈 시계열 예측 | 날짜별 숫자를 넣으면 다음 몇 달 숫자를 예측함 | D3·D4 - 추세·계절성, Holt-Winters |

세 기능 모두 **내 컴퓨터 안에서** 돌아갑니다. API 키도, 비용도 필요 없습니다.

---

## 1단계. 설치하기 (30분)

터미널(맥: 터미널 / 윈도우: Git Bash)을 열고 이 폴더로 이동한 뒤:

```bash
bash env_set_up.sh
```

- 화면에 `[1/4]` → `[2/4]` → `[3/4]` → `[4/4]`가 차례로 나옵니다.
- 맨 마지막에 **`검증 성공: ViT-Tiny 모델 로드 완료`** 가 보이면 성공입니다. 🎉
- 같은 내용이 `env_set_up.log` 파일에도 저장됩니다(제출물).

> 윈도우인데 bash가 없다면 → `INTEGRATION.md` 맨 아래 "Windows PowerShell에서 직접 설치"를 따라 하세요.

## 2단계. 앱 켜기

```bash
source .venv/bin/activate      # 윈도우 Git Bash는: source .venv/Scripts/activate
streamlit run app.py
```

브라우저가 열리고 탭 3개가 보이면 됩니다. 먼저 세 탭을 한 번씩 눌러 구경만 해 보세요.

## 3단계. 탭1 - 이미지 분류 해보기

1. "샘플"에서 `chelsea (고양이)`를 고르고 **분류하기**를 누르세요. (처음 한 번은 조금 기다립니다)
2. 표에 1위~5위 라벨과 확신도(%)가 나옵니다.
3. `astronaut`, `coffee`, 그리고 **내 사진**도 올려보세요.
4. 🤔 생각해보기: **확신도가 낮게 나오는 사진**은 어떤 사진이었나요?
   - 힌트: 이 모델은 ImageNet의 **1,000종 사물**만 배웠습니다. 거기에 없는 것은 비슷한 것으로 착각합니다. (D1)

## 4단계. 탭2 - 이미지 생성 해보기

1. 기본 문장 그대로 **이미지 생성하기**를 누르세요.
   - ⏳ **처음 한 번은 약 1GB 모델을 내려받느라 몇 분 걸립니다. 정상입니다!**
2. 그림 아래에 걸린 시간(초)이 나옵니다.
3. "디노이징 스텝 수"를 **4 → 10 → 30**으로 바꿔가며 같은 문장으로 다시 만들어 보세요.
   - 🤔 스텝이 많을수록 시간과 그림은 어떻게 달라지나요? (D2 - "노이즈를 조금씩 여러 번 지운다")
4. 문장도 **3개 이상** 바꿔 보세요. 영어로 쓰면 더 잘 됩니다. 예:
   - `a cozy cafe interior in autumn, warm orange lighting, watercolor illustration`
   - `a simple friendly illustration of a delivery box being opened, flat design style, pastel colors`
5. 시드(seed)를 그대로 두고 다시 누르면 **똑같은 그림**이 나옵니다. 시드를 바꾸면 다른 그림이 나옵니다.

## 5단계. 탭3 - 시계열 예측 해보기

1. "샘플(AirPassengers)" 상태로 **예측 실행**을 누르세요.
2. 그래프에 실제값(과거)과 예측값(미래 12개월)이 이어서 그려집니다. 여름마다 튀어 오르는 모양까지 예측하는지 보세요.
3. 그래프 아래 **alpha / beta / gamma** 숫자를 메모하세요.

   | 값 | 1에 가까우면 | 0에 가까우면 |
   |---|---|---|
   | alpha (수준) | 최근 값 변화를 빨리 따라감 | 과거 평균을 오래 유지 |
   | beta (추세) | 최근 추세 변화를 빨리 반영 | 추세가 안정적이라 잘 안 바꿈 |
   | gamma (계절성) | 계절 패턴이 해마다 달라진다고 봄 | 계절 패턴이 해마다 같다고 봄 |

4. **내 CSV 만들어 올리기**: 엑셀에서 아래처럼 두 열을 만들고 CSV로 저장하세요(가짜 숫자로 괜찮습니다).

   ```
   date,sales
   2023-01-01,120
   2023-02-01,135
   2023-03-01,150
   ...
   ```

   - 첫 열 = 날짜, 둘째 열 = 숫자. **날짜가 빠짐없이** 이어져야 합니다(매달 1일씩).
   - 월별 데이터로 계절성을 보려면 **최소 24개월** 이상 넣으세요. 짧으면 앱이 "계절성 없이 예측했다"고 알려줍니다.
   - 형식이 헷갈리면 샘플 화면의 **"샘플 CSV 내려받기"** 파일을 열어 보세요.
   - 🤔 계절 패턴이 없는 숫자를 넣으면 gamma는 어떻게 나오나요?

## 6단계. (선택) Claude CLI 해설 켜보기

```bash
USE_CLAUDE_CLI=1 streamlit run app.py
```

(윈도우 PowerShell은 `$env:USE_CLAUDE_CLI="1"; streamlit run app.py`)

- Claude CLI가 설치·로그인되어 있으면 결과 아래에 **"🤖 Claude CLI 해설"** 박스가 생깁니다.
- **설치되어 있지 않으면 박스가 안 생기는 게 정상입니다.** 앱은 그대로 잘 돌아갑니다.
- 박스가 안 떠도 괜찮습니다. **"켜서 실행해봤다"** 는 화면을 캡처하면 됩니다.

## 막히면?

| 이런 일이 생기면 | 이렇게 |
|---|---|
| 앱이 안 켜져요 | 1단계를 끝까지 했는지, 2단계에서 `source ...activate`를 했는지 확인 |
| 그림 생성이 엄청 오래 걸려요 | 처음 한 번은 모델 다운로드 때문. 두 번째부터는 빨라집니다(컴퓨터 성능에 따라 몇 초~십수 초) |
| 분류 결과가 엉뚱해요 | 1,000종에 없는 물건일 수 있어요. 확신도가 낮으면 "사람이 확인 필요" |
| CSV를 못 읽는대요 | 첫 열이 날짜, 둘째 열이 숫자인지, 날짜가 빠진 칸이 없는지 확인 |

> ⚠️ 회사 사진(직원 얼굴, 미공개 제품)이나 실제 매출 숫자는 올리기 전에 한 번 더 생각하세요. 특히 CLI 해설을 켜면 결과 요약이 외부 AI로 전송됩니다. (D1·D2 보안 한 줄)
