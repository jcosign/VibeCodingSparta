# 과제 안내 (아주 쉬운 버전) - 12주차 토요일 프로젝트

> 코딩을 몰라도 괜찮습니다. 앱은 **이미 완성되어 있습니다.**
> 오늘 할 일은 ① 설치하고 ② 3개 탭을 하나씩 써보며 ③ "왜 이렇게 나오지?"를 이번 주 배운 내용으로 설명하고 ④ 화면을 캡처해 내는 것입니다.

## 이 앱이 하는 일 (3가지)

| 탭 | 하는 일 | 이번 주 어디서 배웠나 |
|---|---|---|
| 🧾 이미지 추출 | 영수증 사진 속 글자를 **실제로 읽어서**(OCR) 항목·수량·금액을 JSON으로 정리 | D1(이미지를 읽는다는 것)·D2(이미지 → JSON) |
| 📄 PDF·문서 요약 | PDF에서 글자를 꺼내고, 중요한 문장 3개를 골라 요약 | D3(pypdf·요약·숫자 검증) |
| 🌐 HTML 표 파싱 | 웹 페이지의 표를 엑셀 같은 표로 바꾸고 CSV로 저장 | D4(BeautifulSoup·DataFrame) |

세 기능 모두 기본은 **내 컴퓨터 안에서** 돌아갑니다. API 키도, 비용도, 인터넷도 필요 없습니다.
(교안에서 배운 Gemini는 "선택" 버튼으로 남겨 두었습니다. 키가 없으면 알아서 내 컴퓨터 방식으로 돌아갑니다.)

---

## 1단계. 설치하기 (15분)

### 1-1. Tesseract(글자 읽는 프로그램) 설치

이미지 탭이 사진 속 글자를 읽으려면 **Tesseract**라는 프로그램이 필요합니다. 한 번만 설치하면 됩니다.

- 맥: `brew install tesseract`
- 윈도우: `winget install UB-Mannheim.TesseractOCR`
- 우분투: `sudo apt-get install -y tesseract-ocr`

> 한국어 영수증도 읽히고 싶다면 한국어 언어팩도 설치하세요(INTEGRATION.md 트러블슈팅 참고). 샘플 영수증은 영어라 없어도 됩니다.

### 1-2. 파이썬 환경 설치

터미널(맥: 터미널 / 윈도우: Git Bash)을 열고 이 폴더로 이동한 뒤:

```bash
bash env_set_up.sh
```

- 화면에 `[1/4]` → `[2/4]` → `[3/4]` → `[4/4]`가 차례로 나옵니다.
- `[3/4]`에서 **Tesseract를 찾지 못했다**고 나오면 1-1을 다시 확인하세요.
- 맨 마지막에 **`검증 성공: Tesseract … OCR로 샘플 영수증 2개 항목 인식`** 이 보이면 성공입니다. 🎉
- 같은 내용이 `env_set_up.log` 파일에도 저장됩니다(제출물).

> 윈도우인데 bash가 없다면 → `INTEGRATION.md` 맨 아래 "Windows PowerShell에서 직접 설치"를 따라 하세요.

## 2단계. 앱 켜기

```bash
source .venv/bin/activate      # 윈도우 Git Bash는: source .venv/Scripts/activate
streamlit run app.py           # 또는 bash run.sh
```

브라우저가 열리고 탭 3개가 보이면 됩니다. 왼쪽 사이드바에 **로컬 OCR(Tesseract): 🟢** 이 보이는지 확인하세요.

## 3단계. 🧾 이미지 추출 해보기

1. 아무것도 올리지 않으면 **샘플 영수증**이 보입니다. 엔진은 `local` 그대로 두고 **🔎 정보 추출**을 누르세요.
2. 결과를 위에서부터 보세요.
   - **OCR 원문**: 프로그램이 사진에서 **실제로 읽어낸 글자**입니다. 사진과 똑같나요?
   - **구조화 JSON**: 그 글자를 `이름`·`수량`·`단가`·`금액`·`합계`로 정리한 것.
   - **✅ 검증 통과**: 금액(수량 × 단가)을 다 더한 값이 영수증 합계 39000과 같은지 **코드가 검산**했습니다. (D2 4-2)
3. 내 영수증 사진도 올려 보세요. (⚠️ 카드번호·전화번호는 가리고!)
   - 🤔 OCR 원문은 나오는데 JSON의 `항목`이 비어 있나요? 정상입니다. 지금 규칙은 샘플 형식(`item: … qty: … price: …`)만 읽습니다. 내 영수증 형식을 읽게 고치는 것이 "더 해보기" 과제입니다.
   - 🤔 숫자를 잘못 읽은 곳이 있나요? 글자가 작거나 흐리면 OCR도 틀립니다. 그래서 **검산과 사람 확인**이 필요합니다.
4. (선택) 엔진을 `gemini`로 바꾸고 다시 눌러 보세요. 키가 없으면 **"GEMINI_API_KEY 없음 → 로컬 OCR로 대체"** 안내가 뜨고 결과는 그대로입니다.

## 4단계. 📄 PDF·문서 요약 해보기

1. 아무것도 올리지 않으면 샘플 PDF(`sample_invoice.pdf`)의 글자가 보입니다. **추출 길이**(글자 수)도 확인하세요.
2. **📝 AI 요약**을 누르면 불릿 3개가 나옵니다.
   - 이 요약은 **문장을 새로 쓰지 않고, 원문에서 중요한 문장 3개를 골라 온 것**입니다. 그래서 숫자가 바뀌지 않습니다.
   - 아래 **✅ 요약 속 숫자가 모두 원본 텍스트에 있습니다** 는 요약의 숫자를 원본과 **코드로 대조**한 결과입니다. (D3 4-2)
3. 내 PDF도 올려 보세요(개인정보 없는 것).
   - 🤔 **"글자가 안 뽑혀요 → 스캔본"** 경고가 떴나요? 종이를 찍어 만든 PDF라 글자가 아니라 사진만 들어 있는 겁니다. 그 페이지를 이미지로 저장해 🧾 탭에 올리면 됩니다. (D3 1-3)

## 5단계. 🌐 HTML 표 파싱 해보기

1. 입력칸에 샘플 HTML이 들어 있습니다. **📊 표 파싱**을 누르세요.
2. 카테고리별 매출 표가 나옵니다. **리포트에 넣을 열**에서 `주문수`를 빼 보세요 → "필요한 열만" 리포트. (D4 2-2)
3. **⬇️ CSV 다운로드**로 저장하고 엑셀에서 열어 보세요. 한글이 안 깨지면 성공. (D4 2-3)
4. 입력칸에서 `<table>`…`</table>`을 지우고 다시 누르면 **"표를 찾지 못했습니다."** 가 뜹니다. 앱이 멈추지 않죠? (D4 4-3)
5. 표에 행을 하나 추가해 보세요. 예: `<tr><td>잡화</td><td>500</td><td>120</td></tr>`

## 6단계. (선택) CLI 다듬기 켜보기

```bash
USE_CLAUDE_CLI=1 streamlit run app.py
```

(윈도우 PowerShell은 `$env:USE_CLAUDE_CLI="1"; streamlit run app.py`)

- 📄 탭에서 엔진을 `cli`로 바꾸고 **📝 AI 요약**을 누르세요.
- Claude CLI가 설치·로그인되어 있으면 문장이 더 매끄러워지고, **"비교: 로컬 요약(다듬기 전)"** 을 펼쳐 차이를 볼 수 있습니다.
- **설치되어 있지 않으면 로컬 요약이 그대로 나오는 게 정상입니다.** "켜서 실행해봤다"는 화면을 캡처하면 됩니다.
- CLI가 원문에 없는 숫자를 섞으면 앱이 그 결과를 **버리고** 로컬 요약을 씁니다. "숫자는 원본과 대조"를 코드가 대신 해 주는 것입니다.

## 7단계. 제출하기 ✅

- [ ] `app.py` (안 고쳤으면 원본 그대로 OK)
- [ ] 3탭 화면 캡처 - **특히 🧾 이미지 탭의 OCR 원문**
- [ ] `env_set_up.log` 파일 (또는 "검증 성공" 화면 캡처)
- [ ] 추출 결과 CSV/JSON (🌐 탭 CSV 다운로드 파일, 🧾 탭 JSON 복사본)
- [ ] 데이터 출처 메모 (예: "영수증.jpg - 내가 찍음, 카드번호 가림", "보고서.pdf - 팀 공개 자료")
- [ ] (선택) 엔진을 `cli`/`gemini`로 바꿔 본 화면 캡처 + 로컬과 무엇이 달랐는지 한 줄

## 막히면?

| 이런 일이 생기면 | 이렇게 |
|---|---|
| 앱이 안 켜져요 | 1단계를 끝까지 했는지, 2단계에서 `source ...activate`를 했는지 확인 |
| 사이드바에 "로컬 OCR: 🔴 설치 안 됨" | 1-1의 Tesseract 설치 후 터미널을 새로 열고 앱을 다시 켜기 |
| 내 영수증은 JSON 항목이 비어요 | 정상입니다(샘플 형식만 읽음). OCR 원문이 나오면 OCR은 성공한 것 |
| 엔진을 바꿔도 결과가 똑같아요 | 키·CLI가 없으면 로컬로 대체됩니다. 결과 위의 "실제 사용 경로"와 ℹ️ 안내를 확인하세요 |
| PDF 글자가 안 나와요 | 스캔본입니다. 4단계 3번 참고 |

> ⚠️ 영수증·명함·계약서에는 카드번호·연락처·주민번호 같은 개인정보가 들어 있습니다. 기본(local) 엔진은 내 컴퓨터 밖으로 아무것도 보내지 않지만, `gemini`는 이미지·글을 구글로, `cli`는 요약 문장을 외부 AI로 보냅니다. 켜기 전에 한 번 더 생각하세요. (D2 4-3·D3 4-3)
