# 과제 안내 (아주 쉬운 버전) - 11주차 토요일 프로젝트

> 코딩을 몰라도 괜찮습니다. 앱은 **이미 완성되어 있습니다.**
> 오늘 할 일은 ① 설치하고 ② 3개 탭을 하나씩 써보며 ③ "왜 이렇게 나오지?"를 이번 주 배운 내용으로 설명하고 ④ 화면을 캡처해 내는 것입니다.

## 이 앱이 하는 일 (3가지)

| 탭 | 하는 일 | 이번 주 어디서 배웠나 |
|---|---|---|
| 🔎 검색+리랭크 | 질문을 넣으면 문서들을 "관련 있는 순서"로 줄 세움 (빠른 방법 vs 정확한 방법 비교) | D2 - 임베딩·리랭크 (그 속은 D1의 토큰화·어텐션) |
| 🎙 음성 전사 | 음성 파일을 올리면 글자로 받아 적고, 무슨 언어인지 알려줌 | D3 - Whisper(ASR/STT) |
| 🤖 코드 샌드박스 | 파이썬 코드를 넣으면 따로 떨어진 공간에서 실행하고 결과만 보여줌 | D4 - 코드 실행 샌드박스(E2B) |

세 기능 모두 **내 컴퓨터 안에서** 돌아갑니다. API 키도, 비용도 필요 없습니다.

---

## 1단계. 설치하기 (30분)

터미널(맥: 터미널 / 윈도우: Git Bash)을 열고 이 폴더로 이동한 뒤:

```bash
bash env_set_up.sh
```

- 화면에 `[1/5]` → `[2/5]` → … → `[5/5]`가 차례로 나옵니다.
- `[4/5]`에서 **ffmpeg가 없다**고 나오면, 안내된 명령으로 설치하세요(음성 전사 탭에 꼭 필요합니다).
  - 맥: `brew install ffmpeg` / 윈도우: `winget install Gyan.FFmpeg` (설치 후 터미널을 새로 여세요)
- 맨 마지막에 **`검증 성공: 임베딩 모델 로드 완료`** 가 보이면 성공입니다. 🎉
- 같은 내용이 `env_set_up.log` 파일에도 저장됩니다(제출물).

> 윈도우인데 bash가 없다면 → `INTEGRATION.md` 맨 아래 "Windows PowerShell에서 직접 설치"를 따라 하세요.

## 2단계. 앱 켜기

```bash
source .venv/bin/activate      # 윈도우 Git Bash는: source .venv/Scripts/activate
streamlit run app.py
```

브라우저가 열리고 탭 3개가 보이면 됩니다. 먼저 세 탭을 한 번씩 눌러 구경만 해 보세요.

## 3단계. 탭1 - 검색+리랭크 해보기

1. 기본으로 들어 있는 질문("환불 어떻게 하나요?")과 문서 4개 그대로 **검색 실행**을 누르세요. (처음 한 번은 조금 기다립니다)
2. 왼쪽 표(① 바이 인코더)와 오른쪽 표(② 크로스 인코더)를 비교하세요.
   - 🤔 왼쪽에서 **"오늘 서울 날씨는 맑습니다."** 가 2위에 있지 않나요? 질문과 아무 상관 없는데 말이죠.
   - 오른쪽에서는 날씨가 꼴찌, **반품** 문서가 2위입니다. (D2 2-4와 같은 숫자가 나옵니다)
3. 이번엔 문서 칸을 지우고 아래 4줄을 붙여 넣은 뒤, 질문을 `주문한 물건이 아직 안 왔어요`로 바꿔 보세요.

   ```
   배송 조회는 주문내역에서 운송장 번호로 확인 가능합니다.
   결제 수단은 신용카드와 계좌이체를 지원합니다.
   오늘의 미세먼지 농도는 보통입니다.
   배송이 지연되면 고객센터로 문의해주세요.
   ```

   - 두 표의 **1위가 다르면** 노란 경고가 뜹니다. 어느 쪽이 맞아 보이나요?
4. 내 업무 문서(FAQ, 사내 공지 등) 4~5개와 질문으로도 해 보세요.
   - 힌트: 바이 인코더는 **빠르지만** 문장을 숫자 하나(벡터)로 뭉개다 보니 헷갈릴 때가 있고, 크로스 인코더는 **느리지만** 질문과 문서를 직접 맞대어 봅니다. 그래서 실무는 "넓게 찾고 → 정확하게 다시 줄 세우기"를 씁니다. (D2)
   - 크로스 인코더도 **가끔 틀립니다**(D2 2-5 사례 A). 결과는 사람이 한 번 더 확인하세요.

## 4단계. 탭2 - 음성 전사 해보기

1. 음성 파일을 준비하세요. 아무거나 괜찮습니다.
   - 스마트폰 음성 메모(m4a), 직접 녹음한 wav/mp3
   - D3 예제(`Week11_Day3_example_02_tts_to_asr_roundtrip.py`)로 만든 샘플 음성
2. 파일을 올리고 **전사 실행**을 누르세요.
   - ⏳ **처음 한 번은 약 72MB 모델을 내려받느라 기다립니다. 정상입니다!**
3. 전사 결과와 **감지된 언어**(`en` = 영어, `ko` = 한국어)를 확인하세요.
4. **한국어 음성**과 **영어 음성**을 하나씩 넣어 언어가 맞게 나오는지 보세요.
   - 🤔 틀린 단어가 있었나요? 회사 이름·제품명·전문용어에서 많이 틀립니다. (D3 3-5 - 소음·전문용어·억양)
   - 그래서 전사 결과는 **사람이 확인**한 뒤에 회의록 등에 써야 합니다.

## 5단계. 탭3 - 코드 샌드박스 해보기

1. 기본 코드 그대로 **코드 실행**을 누르세요. → 상태 **완료**, stdout에 `1~100 합계: 5050`
2. 코드를 아래로 바꾸고, 시간 제한을 **2초**로 내린 뒤 실행하세요. (끝나지 않는 코드입니다)

   ```python
   while True:
       pass
   ```

   → 2초 뒤 **시간초과(강제종료)**. 앱 전체는 멈추지 않습니다. 이게 "따로 떨어진 공간에서 실행"하는 이유입니다. (D4)
3. 일부러 틀린 코드도 넣어 보세요. → **오류**, stderr에 이유가 나옵니다.

   ```python
   print(1 / 0)
   ```

4. 화면 위쪽의 **"E2B_API_KEY가 없어 로컬 대체 샌드박스를 사용했습니다"** 안내를 확인하세요. E2B 키가 없어도 앱이 알아서 로컬로 넘어갑니다.
   - ⚠️ 이 로컬 샌드박스는 **공부용**입니다. 내 컴퓨터 파일에 접근하는 코드를 막아 주지는 못합니다. 모르는 코드는 넣지 마세요.
   - "안전하게 실행됐다" ≠ "결과가 정확하다". 계산 결과는 사람이 확인하세요. (D4 4-2)

## 6단계. (선택) Claude CLI 해설 켜보기

```bash
USE_CLAUDE_CLI=1 streamlit run app.py
```

(윈도우 PowerShell은 `$env:USE_CLAUDE_CLI="1"; streamlit run app.py`)

- Claude CLI가 설치·로그인되어 있으면 결과 아래에 **"🤖 Claude CLI 해설"** 박스가 생깁니다.
- **설치되어 있지 않으면 박스가 안 생기는 게 정상입니다.** 앱은 그대로 잘 돌아갑니다.
- 박스가 안 떠도 괜찮습니다. **"켜서 실행해봤다"** 는 화면을 캡처하면 됩니다.

## 7단계. 제출하기 ✅

- [ ] 탭1 캡처: 바이 인코더 / 크로스 인코더 두 순위표
- [ ] 탭2 캡처: 전사 결과 + 감지된 언어
- [ ] 탭3 캡처: 코드 실행 결과 (완료 / 시간초과 / 오류 중 1개 이상)
- [ ] `env_set_up.log` 파일 (또는 "검증 성공" 화면 캡처)
- [ ] (선택) `USE_CLAUDE_CLI=1`로 실행한 화면 캡처
- [ ] 내가 쓴 오디오 파일·문서 목록 메모 (예: "회의메모.m4a - 내가 녹음", "FAQ 5개 - 우리 팀 공지에서 발췌")
- [ ] `app.py`, `local_model.py`, `cli_augment.py` (안 고쳤으면 원본 그대로 OK)

## 막히면?

| 이런 일이 생기면 | 이렇게 |
|---|---|
| 앱이 안 켜져요 | 1단계를 끝까지 했는지, 2단계에서 `source ...activate`를 했는지 확인 |
| 음성 전사에서 오류가 나요 | ffmpeg가 설치되어 있는지 확인(`ffmpeg -version`). 설치 후 터미널을 새로 열고 앱을 다시 켜기 |
| 두 순위표가 항상 똑같아요 | 문서를 4개 이상, 서로 다른 주제로 넣어 보세요 |
| 코드가 계속 로컬로만 실행돼요 | 정상입니다. E2B 키가 없으면 로컬 샌드박스를 씁니다 |
| 처음 실행이 너무 오래 걸려요 | 모델을 처음 내려받는 중입니다. 두 번째부터는 빨라집니다 |

> ⚠️ 회의 녹음·고객 문의에는 이름·전화번호 같은 개인정보나 회사 기밀이 들어 있을 수 있습니다. 올리기 전에 한 번 더 생각하세요. 특히 CLI 해설을 켜면 전사 결과·검색 결과가 텍스트로 외부 AI에 전송됩니다. (D3 4-3·D4 보안 한 줄)
