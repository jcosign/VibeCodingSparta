# 과제 안내 (쉬운 버전) — AI 업무 비서 대시보드

**한 줄:** 이미 돌아가는 3탭 앱(`app.py`)을 켜 보고, **필터 · 요약 톤 · 부정 비율** 세 가지를 붙여 "내 앱"으로 만듭니다.
**API 키가 없어도 됩니다.** 키가 없으면 AI 요약은 mock(가짜 AI, 무료)으로 끝까지 돌아갑니다.

> 매 단계 끝에 **검증**을 합니다: `python3 examples/example_01_integrated_report.py` → 마지막 줄 `END-TO-END OK`
> (Windows에서 `python3`가 없으면 `python`으로 바꿔 입력하세요.)

## 1단계 (30분) 실행하고 3탭 둘러보기
```bash
cd project
pip install -r requirements.txt     # 최초 1회
./run.sh                            # → http://localhost:8610
```
- Windows PowerShell처럼 bash가 없으면: `streamlit run app.py --server.port 8610`
- 사이드바에 **🟡 mock (키 없이 동작)** 이 보이면 정상입니다.
- 🤖 탭에서 **[AI 요약 만들기]**, 💬 탭에서 **[분류하기]** 를 눌러 보세요.
- 📸 **3탭 화면을 1장씩 캡처**(제출물).

## 2단계 (50분) 코드 읽기 + 예제 실행
```bash
python3 data.py                                    # 총매출·총주문·평균 별점 확인
python3 examples/example_01_integrated_report.py   # 지표(원본) → 요약(참고) → 토큰/비용 → END-TO-END OK
python3 examples/example_02_review_pipeline.py     # 감정 분포 → 카테고리별 부정 비율
```
읽으면서 찾아볼 것 (`app.py`):
- `st.set_page_config` 가 맨 위에 있는 이유
- `st.tabs([...])` 와 `with tab1:` 블록
- `digest` - AI에 보내는 건 원본 행이 아니라 **집계 요약 한 줄**
- `if st.button(...)` 안에서만 `ask()` 를 부르는 이유(rerun마다 호출하면 요금 폭탄)
- `max_tokens=300` (출력이 곧 돈)

📝 메모: "부정 비율이 가장 높은 카테고리는 ___"

## 3단계 (60분) 대시보드에 필터(기간/지역) 추가
`app.py` 의 `[과제 3단계]` 위치를 고칩니다.
- **기간:** `orders["날짜"]` 로 시작일~종료일 슬라이더 (`st.slider` 는 날짜 범위를 받을 수 있어요)
- **지역:** 선택 상자, 선택지는 `전체` + 서울/경기/부산/대구/광주, 기본값 `전체`
- 필터된 데이터로 **지표 3개 · 차트 · digest** 가 모두 다시 계산되어야 합니다.
- 필터 결과가 0건일 때 앱이 죽지 않게 처리하세요.

✅ 검증: example_01 실행 + **"서울만 골랐을 때 총매출이 전체보다 작아지는가?"** 눈으로 대조.

💡 CLI 도구(`claude`/`codex`)로 할 때 좋은 지시 예 (교재 D4):
```
app.py 대시보드 탭에 '지역 필터(선택 상자)'를 추가해줘.
- data.py orders의 '지역' 컬럼 값(서울/경기/부산/대구/광주)을 선택지로 만들어줘.
- '전체'를 포함하고, 기본값은 '전체'로 해줘.
- 고른 지역에 맞춰 위쪽 지표 3개와 차트가 다시 계산되게 해줘.
- 끝나면 example_01을 실행해 오류 없는지 확인해줘.
```
도구가 보여주는 **변경안(diff)을 읽고** 승인하고, 시작 전에 폴더를 **백업**해 두세요.

## 4단계 (60분) AI 요약 프롬프트 다듬기 (경영진용/실무진용)
`app.py` 의 `[과제 4단계]` 위치(`system = ...`)를 고칩니다.
- `st.radio` 등으로 **경영진용 / 실무진용** 을 고르게 하고, 고른 톤에 맞는 system 프롬프트를 씁니다.
- 프롬프트 4요소(역할·맥락·지시·출력형식)를 담고, **"주어진 숫자만 쓰고 새로운 숫자를 만들지 마"** 처럼 범위를 좁히세요.
- ⚠️ mock 모드에서는 톤을 바꿔도 요약 문장이 같습니다(규칙 기반). 톤 차이는 실제 키를 켰을 때 보입니다.

✅ 검증: 요약 결과 + 모드·토큰·비용이 보이는지, **요약 속 숫자를 digest(원본)와 대조**. 📸 AI 요약 결과 캡처(제출물).

## 5단계 (40분) 리뷰 분류 결과에 카테고리별 부정 비율 추가
`app.py` 의 `[과제 5단계]` 위치에 추가합니다. `examples/example_02_review_pipeline.py` 의 계산을 참고하세요.
