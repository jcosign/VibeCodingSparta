# 6주차 토요일 프로젝트 (쉬운 버전) — 데이터 리포트 웹앱 만들기

> **Vibe Coding 과제**: Claude Code(또는 Codex CLI)에게 시켜서, 데이터를 만들고→정리하고→AI로 분석하고→보고서·API·웹앱까지 완성합니다.
> **난이도:** 하 (초보자용) · **소요:** 2~3시간 · **웹 UI:** Streamlit · **AI:** mock(키 불필요) 기본, 원하면 로컬 claude/codex CLI 연동
> **완성 예시가 `solution/`에 있고, 테스트 완료(ALL PASS)했습니다.** 모든 설치·실행은 **내 PC(로컬)** 에서 합니다(컨테이너·서버 없음).

---

## 0. 이 과제로 무엇을 얻나요
가짜 판매 데이터로 시작해서 **"데이터 → 정리 → AI 분석 → 보고서(CSV·PDF) → API → 웹앱"** 전 과정을
직접 만든 경험을 얻습니다. 다 만들면:
- 버튼만 누르면 되는 **웹앱**(`streamlit run app.py`)
- **CSV·PDF 보고서**, 데이터를 받아가는 **API**, 사용법 **HTML 문서**
- 이 모든 걸 **Claude Code/Codex에게 시켜서 만든** Vibe Coding 경험

---

## 1. 진행 방법 (딱 3가지만 기억)

### 방법 A. Vibe Coding으로 직접 만들기 (과제)
1. 이 폴더의 **`problem.md`** 와 **`env.md`** 를 엽니다.
2. Claude Code(또는 Codex CLI)에 두 파일 내용을 붙여넣고 이렇게 말합니다:
   > "아래 problem.md와 env.md를 읽고, STEP 1부터 6까지 파일을 **하나씩** 만들어줘.
   > 각 파일을 만들면 **실제로 실행해서 확인**하고 다음으로 넘어가줘. 마지막에 `test_solution.py`로 검증해줘."
3. AI가 만드는 코드를 보면서 한 단계씩 실행해 봅니다. 막히면 "이 오류 고쳐줘"라고 하면 됩니다.

### 방법 B. 완성 예시 먼저 돌려보기 (추천 시작점)
> **먼저 되는 걸 눈으로 보고 시작**하면 훨씬 쉽습니다.
```bash
cd solution
pip install -r requirements.txt     # 내 PC에 설치 (가상환경 권장)
python3 test_solution.py            # 6단계 전부 자동 검증 → "ALL PASS"
streamlit run app.py                # 웹앱 열기 → 브라우저 http://localhost:8501 (사이드바 1→2→3→4 클릭)
```

## 2. 만들 6단계 (한눈에)

| STEP | 파일 | 하는 일 | 결과물 |
| --- | --- | --- | --- |
| 1 | `generate_data.py` | 가짜 판매 데이터 10,000개 (결측·이상치 포함) | `data/raw_sales.csv` |
| 2 | `preprocess.py` | pandas로 정리(중복·이상치·결측) → DB | `data/sales.db`, `clean_sales.csv` |
| 3 | `analyze.py` | AI 분석 (mock / claude / codex) | `data/analysis.json` |
| 4 | `report.py` | CSV·PDF 보고서 | `reports/*.csv`, `report.pdf` |
| 5 | `api.py` | FastAPI로 데이터 제공 + 예제 | `/summary`, `/data`, `/docs` |
| 6 | `app.py`, `docs.html` | 웹 UI + HTML 설명서 | 브라우저 대시보드 |

## 3. 성공 기준 (이게 되면 성공) ✅

- [ ] `python3 test_solution.py` 가 **ALL PASS** 로 끝난다.
- [ ] `streamlit run app.py` 로 웹앱이 뜨고, 버튼 1→2→3→4로 지표·그래프·표가 나온다.
- [ ] `reports/`에 **CSV와 PDF 보고서**가 만들어진다.
- [ ] `uvicorn api:app --port 8600` 후 `http://localhost:8600/docs` 가 열리고 `/summary`가 값을 준다.
- [ ] `docs.html`을 열면 사용법이 보인다.
- [ ] (선택) `AI_MODE=claude` 또는 `codex`로 실제 AI 분석을 1회 시도(실패해도 mock으로 자동 전환).

## 5. 자주 막히는 곳 (FAQ)

- **"DB가 없다"고 나와요** → 1)데이터 생성 → 2)전처리를 **먼저** 실행하세요.
- **웹앱 주소가 뭐예요** → 로컬이라 브라우저에서 `http://localhost:8501`(웹앱) / `http://localhost:8600/docs`(API)로 바로 열립니다. 포트가 겹치면 `--server.port 8502` 처럼 바꾸세요.
- **PDF에 한글이 깨져요** → PC에 한글 폰트가 없으면 **PDF는 영문 라벨**을 씁니다(정상). 한글은 화면·CSV·HTML에 있습니다.
- **claude/codex가 mock으로 떨어져요** → 정상입니다. 로컬에 CLI가 없거나 로그인이 안 되면 자동으로 mock을 씁니다.
- **AI가 만든 코드에 오류가 나요** → 오류 메시지를 그대로 복사해 "이 오류 고쳐줘"라고 하세요(Vibe Coding의 핵심).
