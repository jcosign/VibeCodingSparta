판매 분석 리포트

가상 판매 데이터 생성, 정리, 분석, 보고서 및 API 사용 안내

설치

Python 3.10 이상을 설치한 뒤 solution 폴더에서 필요한 패키지를 설치합니다.

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

단계별 실행

할인율은 0에서 0.30 사이의 비율로 저장합니다(예: 0.15는 15%). 총액은 할인 전 금액이며, 할인 금액과 할인 후 금액도 함께 계산합니다. 지역·카테고리 요약과 대시보드 및 PDF 차트에는 평균 할인율과 할인 후 매출이 반영됩니다.

단계명령결과
1. 데이터 생성python generate_data.py 10000data/raw_sales.csv
2. 전처리 및 DBpython preprocess.pydata/sales.db, reports/*.csv
3. AI 분석python analyze.pydata/analysis.json
4. 보고서 생성python report.pyreports/*.csv, report.pdf
5. API 실행uvicorn api:app --port 8600API 문서
6. 웹앱 실행streamlit run app.pyStreamlit 대시보드

웹앱

Streamlit 사이드바의 데이터 생성, 전처리, AI 분석, 보고서 만들기 버튼을 순서대로 누릅니다. 카테고리 필터에서 하나 이상을 선택하면 지표, 그래프, 표와 CSV 다운로드에 선택한 카테고리만 반영됩니다. AI 분석과 PDF는 전체 데이터 기준입니다.

AI 모드

기본값은 API 키가 필요 없는 mock 분석입니다. 로컬 CLI를 설치하고 로그인한 경우에만 실제 분석을 시도할 수 있습니다. CLI가 없거나 실패하면 mock으로 자동 전환됩니다.

# Windows PowerShell
$env:AI_MODE = "claude"
python analyze.py

# 또는 Codex CLI
$env:AI_MODE = "codex"
python analyze.py

API와 예제

API를 실행한 다음 브라우저의 /docs에서 확인합니다.

  • GET /summary: 지역별·카테고리별 요약
  • GET /data?limit=5: 정리된 판매 데이터 (최대 1,000건)
  • GET /top?category=전자제품&limit=5: 카테고리별 할인 후 매출 상위 주문 (최대 100건)
  • GET /analysis: AI 또는 mock 분석 결과
  • GET /report.csv: 정리 데이터 CSV 다운로드

requests 예제: python examples/api_client_example.py
