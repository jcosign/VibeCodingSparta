# 9주차 프로젝트 평가지표 (아주 심플)

> **주제:** 매출 대시보드 + 리뷰 분류기 (Streamlit 2탭). **난이도:** 중상.
> 6개 지표, 각 **10점**(총 60점). 자동 채점은 `채점.py`로 할 수 있습니다.
> 자동 채점은 **서버를 띄우지 않고** 파일 존재 + 함수 정의(ast) + 핵심 문자열(마커)만으로 판정합니다.

---

## 1. 6개 평가지표 (각 10점)

| # | 지표 | 충족 기준(이게 되면 O) | 점수 |
|---|---|---|---|
| **①** | **제출** | 과제 파일(.py 등)을 제출함 | 10 |
| ② | **데이터(data.py)** | `data.py`에 `sales_df()`·`reviews_df()`가 있어 **합성 매출·리뷰**를 만든다 | 10 |
| ③ | **분류기(classifier)** | `classifier.py`에 `classify()`가 있고 **rule(기본)·hf(선택)** 두 방식 흔적이 있다 | 10 |
| ④ | **대시보드 탭** | `app.py`에 **탭 + 매출 지표(metric) + 차트(line/bar)** 가 있다(탭1) | 10 |
| ⑤ | **분류 탭(표·CSV)** | `app.py`에서 `classify()`로 분류 → **결과 표(dataframe) + CSV 다운로드** 가 있다(탭2) | 10 |
| ⑥ | **멀티 백엔드/HF** | `ai_backend.py`가 있거나(=`ask()`), **`CLF_MODE=hf`/HuggingFace 연동 흔적**이 있다 | 10 |

> ①(제출)을 제외한 **나머지 5개(②~⑥)** 로 상/중/하를 정합니다.

---

## 2. 상 / 중 / 하 판정 (아주 간단)

| 등급 | 조건 | 예시 점수 |
|---|---|---|
| **하** | **제출함** (①) — 나머지 ②~⑥ 중 0~2개 충족 | 10~30점 |
| **중** | 나머지 ②~⑥ 중 **정확히 3개** 충족 | 40점 |
| **상** | 나머지 ②~⑥ 중 **4개 이상** 충족 | 50~60점 |

- **제출만 해도 '하'** 입니다.
- 나머지 지표 **3개 = 중**, **3개 초과(4~5개) = 상**.
- (미제출 시에는 등급 없음 / 0점)

### 한눈 요약
```
제출  →  하
제출 + (②~⑥ 중 3개)      →  중
제출 + (②~⑥ 중 4~5개)   →  상
```

---

## 3. 자동 채점 방법 (권장)

학생이 제출한 폴더에서 아래를 실행하면 점수·등급이 자동으로 나옵니다.
```bash
python3 채점.py .            # 현재 폴더(제출물)를 채점
# 또는 학생 제출 폴더 경로 지정:  python3 채점.py /경로/학생폴더
```
출력 예:
```
① 제출                 [O] 10점  · 파이썬 파일 제출됨
② 데이터(data.py)       [O] 10점  · data.py: sales_df·reviews_df 정의됨(합성 매출·리뷰)
③ 분류기(classifier)    [O] 10점  · classifier.py: classify()·rule(기본)·hf(선택) 확인
④ 대시보드 탭             [O] 10점  · app.py: 탭·metric·차트(line/bar) 확인(매출 대시보드)
⑤ 분류 탭(표·CSV)        [X]  0점  · classify=True, table=True, csv=False
⑥ 멀티 백엔드/HF          [O] 10점  · ai_backend.py: ask() 멀티 백엔드 존재
----------------------------------------------------
총점: 50 / 60  |  나머지(②~⑥) 충족: 4개  →  등급: 상
```

> 자동 채점은 **파일의 존재·구조**를 확인합니다. 코드 품질·창의성은 필요하면 채점자가 가점하세요.

## 4. 수동 체크리스트 (자동 채점 없이도 가능)

- [ ] ① 제출했다(.py 파일이 있다).
- [ ] ② `python3 data.py` 실행 → 매출·리뷰 데이터 크기가 출력된다(`sales_df`·`reviews_df`).
- [ ] ③ `python3 classifier.py` 실행 → 긍정/부정/중립 예시가 출력된다(rule 기본, hf 선택).
- [ ] ④ `streamlit run app.py`의 **탭1**에 지표 + line/bar 그래프가 보인다.
- [ ] ⑤ **탭2**에서 리뷰 분류 → 표 + **CSV 다운로드 버튼**이 나온다.
- [ ] ⑥ `ai_backend.py`가 있거나, `CLF_MODE=hf`로 HuggingFace 분류가 연동된다.

충족한 ②~⑥ 개수로 상/중/하를 매기면 됩니다.
