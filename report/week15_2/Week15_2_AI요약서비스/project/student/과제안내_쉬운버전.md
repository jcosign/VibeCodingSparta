# 과제 안내 (쉬운 버전) — 배포용 AI 요약 서비스

**한 줄:** 글을 붙여넣으면 요약해 주는 앱을 내 컴퓨터에서 띄우고, 할 수 있으면 인터넷 주소(URL)로 공개합니다.
**API 키가 없어도 됩니다.** 키가 없으면 가짜 요약(mock)으로 끝까지 돌아갑니다.

## 1단계. 준비 (최초 1회)
```bash
cd project/student
bash env_set_up.sh
```
- 마지막 부분에 `mock 응답: [MOCK 요약] ...`이 보이면 성공입니다.
- 전체 기록은 `env_set_up.log`에 저장됩니다.
- Windows는 **Git Bash**나 **WSL**에서 실행하세요.

## 2단계. 내 컴퓨터에서 실행 (← 가장 중요, 1순위)
```bash
./run.sh
```
- 브라우저에서 `http://localhost:8615` 열기 → **✍️ 요약하기** 버튼 누르기
- 사이드바에 `🟡 mock(키 없이)`과 `PORT: 8615`가 보이게 **캡처**하세요(제출물).
- 끄기: 터미널에서 `Ctrl + C`

## 3단계. (선택) 진짜 Gemini 쓰기
```bash
export GEMINI_API_KEY=내키      # 코드나 파일에 키를 적지 마세요!
./run.sh
```
사이드바가 `🟢 Gemini (키 있음)`으로 바뀝니다.

## 4단계. 배포 (할 수 있는 만큼)
- **방법 1:** Google AI Studio의 Deploy 버튼 → `...run.app` 주소 받기
- **방법 2:** `docker build -t ai-summary .` → 성공 로그 캡처
- 자세한 방법: `INTEGRATION.md`
- 배포가 안 돼도 괜찮습니다. **완성·검증이 우선, 배포는 선택**입니다.

## 5단계. 안전 설정
- 키는 **환경변수/시크릿**으로만 넣기
- 클라우드를 썼다면 **월 예산(비용 상한) + 알림** 설정 후 캡처
- 개인정보(이름·전화·이메일)는 요약창에 넣기 전에 가리기
