# 13주차 과제 - 아주 쉬운 안내 🔎

## 이번 과제를 한 문장으로

> **"질문을 하면, 우리 회사 FAQ 문서 중에서 뜻이 가장 비슷한 것을 찾아 '이 문서에 이렇게 적혀 있어요'라고 출처와 함께 보여 주는 웹 화면"** 을 직접 켜 보고 실험하는 과제입니다.

코드는 이미 완성되어 있습니다. 여러분은 **설치 → 실행 → 질문해 보기 → 캡처** 만 하면 됩니다.
API 키도, 돈도 필요 없습니다. 모든 계산이 내 컴퓨터 안에서 일어납니다.

---

## 이번 주에 배운 것이 어디에 들어 있나요?

이번 주는 '오픈북 시험'을 보는 AI를 만드는 주였어요.

| 배운 날 | 한 줄 요약 | 이 과제의 어느 파일? |
|---|---|---|
| D1 | AI는 모르면 지어낸다 → 먼저 **찾아보고** 답하게 하자(RAG) | `rag.py`가 답할 때 항상 근거 문서를 함께 돌려줌 |
| D2 | 문장을 **숫자 목록(벡터)** 으로 바꾸면 '비슷함'을 계산할 수 있다 | `embed.py` |
| D3 | 벡터를 **창고(Chroma)** 에 넣어 두고 빠르게 꺼낸다 | `rag.py` |
| D4 | 긴 글은 **잘라서** 넣고, 답에는 **출처**를 붙인다 | `docs.py`의 `chunk()`, `rag.py`의 `answer()` |

이번 과제에서 달라진 점 딱 하나: D2에서는 글자가 겹치는지만 세는 **흉내 임베딩**을 썼지만, 이번에는 **진짜 임베딩 모델**(`intfloat/multilingual-e5-small`, 한국어도 이해하는 모델)을 씁니다. 그래서 "돈을 다시 돌려받고 싶어요"처럼 '환불'이라는 글자가 없어도 환불 문서를 찾아냅니다.

## 따라 하기 (명령어는 복사해서 붙여 넣으세요)

### 1단계. 과제 폴더로 이동

```bash
cd project/student
```

### 2단계. 환경 설정 (처음 한 번만, 몇 분 걸려요)

```bash
bash env_set_up.sh
```

- 필요한 프로그램을 설치하고, 임베딩 모델(약 450MB)을 내려받습니다.
- 마지막 줄 근처에 **`검증 성공: 임베딩 모델 로드 완료`** 가 보이면 성공!
- 이 과정의 기록은 `env_set_up.log` 파일에 저장됩니다(제출물).

> 💡 Windows에서 `bash`가 없다면: Git Bash를 쓰거나, PowerShell에서 아래처럼 직접 해도 됩니다.
> ```powershell
> py -3.12 -m venv .venv
> .\.venv\Scripts\python.exe -m pip install -r requirements.txt
> .\.venv\Scripts\python.exe embed.py
> ```

### 3단계. 가상환경 켜기 (터미널을 새로 열 때마다)

```bash
source .venv/bin/activate        # macOS / Linux
source .venv/Scripts/activate    # Windows Git Bash
```

### 4단계. 부품 하나씩 돌려 보기

```bash
python3 docs.py      # 문서 8개 + 청킹 예시
python3 embed.py     # 문장 → 384개 숫자(소수점이 있는 진짜 벡터)
python3 rag.py       # 질문 → 비슷한 문서 찾기 → 출처와 함께 답
```

`rag.py` 결과에서 **"반품하고 싶어요" 의 근거 1위가 `반품정책`** 인지 확인하세요.

### 5단계. 웹앱 켜기

```bash
streamlit run app.py
```

브라우저가 열리면:
1. 예시 질문 버튼을 눌러 보거나, 직접 질문을 입력하세요.
2. **답변** 과 **근거(출처) 표** 가 나오는지 확인하세요.
3. 왼쪽 사이드바에서 **근거 문서 수(k)** 를 1 → 3으로 바꿔 보세요. 근거 표가 늘어나요.

### 6단계(선택). CLI로 답변 다듬기 체험

```bash
USE_CLAUDE_CLI=1 streamlit run app.py
```

- Claude CLI가 설치되어 있으면 "🤖 Claude CLI가 다듬은 답변" 박스가 나타납니다.
- **설치되어 있지 않으면 박스가 안 보이는 게 정상입니다.** 그 화면을 그대로 캡처하면 됩니다. "켜서 실행해 봤다"는 기록이 중요해요.

## 꼭 해 볼 실험 3가지

| 실험 | 질문 예시 | 눈여겨볼 것 |
|---|---|---|
| ① 있는 것 | 반품하고 싶어요 | 반품정책이 1위로 나오나요? 유사도 점수는? |
| ② 글자는 다르지만 뜻이 같은 것 | 돈을 다시 돌려받고 싶어요 | '환불' 글자가 없어도 환불처리를 찾나요? (1위와 2위 점수 차이도 보세요!) |
| ③ 문서에 없는 것 | 해외 배송도 되나요? / 우리 회사 주가 얼마예요? | "못 찾았다"고 하나요, 아니면 비슷한 문서를 보여 주나요? |

③에서 **"해외 배송"은 배송기간 문서가 그대로 나옵니다.** 이 모델은 점수가 0.78~0.91 사이로 몰려 있어서, 관련 없는 질문도 꽤 높은 점수를 받기 때문이에요(자세한 숫자는 `INTEGRATION.md` §4). 그래서 **AI 답을 그대로 믿지 말고 출처를 열어 확인하는 습관**이 중요합니다(D4 4-2).
