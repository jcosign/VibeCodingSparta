# 15-1주차 토요일 과제 - LangChain 업무 비서 🤖 (쉬운 버전)

**한 줄 목표:** 도구(계산·FAQ)를 쓰고, 대화를 기억하는 채팅 비서를 띄운다.
API 키는 없어도 됩니다. 이 컴퓨터에서 도는 로컬 LLM(Qwen2.5-0.5B-Instruct)이 답합니다.

## 이번 주 배운 것이 어디에 있나

| Day | 배운 것 | 이 프로젝트의 위치 |
|---|---|---|
| D1 | LCEL `prompt \| llm` 체인 | `examples/example_01_prompt_template.py` |
| D2 | PromptTemplate 재사용 | `agent.py`의 `PROMPT` |
| D3 | 도구 + 라우팅 | `agent.py`의 `calc`·`faq`·`TOOLS`·`_route()` |
| D4 | 메모리 | `agent.py`의 `self.history` (최근 6줄을 `{history}`에) |

## 1단계 - 설치 (최초 1회)

```bash
cd project/student
bash env_set_up.sh
```

- 끝에 `검증 성공: 로컬 LLM 응답 = ...` 이 보이면 성공입니다.
- 첫 실행은 모델을 내려받아 시간이 걸립니다(인터넷 필요).
- 로그는 `env_set_up.log`에 자동 저장됩니다(제출물).

## 2단계 - 실행

```bash
source .venv/bin/activate     # Windows Git Bash: source .venv/Scripts/activate
streamlit run app.py          # 또는: bash run.sh
```

사이드바 모드가 **🟢 local** 인지 확인하세요.

## 3단계 - 순서대로 입력해 보기

1. `내 이름은 홍길동이야` → LLM이 답함
2. `12*8 계산해줘` → `[calc] 96` (도구)
3. `환불 규정 알려줘` → `[faq] 환불은 반품 도착 후 3영업일 이내 처리됩니다.` (도구)
4. `내 이름 뭐였지?` → 이름을 **기억해서** 답하는지 확인 (메모리)

> 0.5B는 아주 작은 모델이라 답이 어색하거나 틀릴 수 있습니다. 그것도 관찰 포인트예요.
> 이름을 잘 못 맞히면 `LOCAL_LLM_MODEL=Qwen/Qwen2.5-1.5B-Instruct` 로 바꿔 비교해 보세요.

## 4단계 - app.py 고치기

제출물은 **app.py 수정본**입니다. 아래는 예시이니 하나 이상 골라 해 보세요.

- 사이드바에 내 이름과 비서 소개 문구 추가
- 예시 질문 4개를 버튼으로 만들어, 누르면 바로 `agent.chat()` 실행
- 도구 응답(`[calc]`/`[faq]`)과 LLM 응답을 다른 아이콘으로 표시
